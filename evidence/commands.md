ЖУРНАЛ ВЫПОЛНЕННЫХ КОМАНД

1. Проверка системы
Команды: whoami, id, pwd, cat /etc/os-release, uname -m
Назначение: определение пользователя, текущего каталога, версии ОС и архитектуры.
Ожидаемый результат: сведения об установленной Ubuntu.
Фактический результат: пользователь yar, Ubuntu 24.04.5 LTS, архитектура x86_64.

2. Навигация по каталогам
Команды: cd "$HOME", pwd, cd ../..
Назначение: переход между каталогами и определение текущего пути.
Ожидаемый результат: корректное изменение рабочего каталога.
Фактический результат: переход в /home/yar и между каталогами лабораторной выполнен успешно.

3. Создание каталогов и файлов
Команды: mkdir -p, mkdir, touch, ls -la
Назначение: создание структуры лабораторной и просмотр её содержимого.
Ожидаемый результат: создание каталогов data, backup, evidence.
Фактический результат: каталоги и файл hello_linux.txt созданы.

4. Редактирование файла
Команды: nano data/hello_linux.txt, cat data/hello_linux.txt
Назначение: запись и просмотр текстовой информации.
Ожидаемый результат: сохранение трёх строк.
Фактический результат: три строки успешно записаны и выведены.

5. Копирование и переименование
Команды: cp, mv, ls -l
Назначение: создание резервной копии и переименование оригинала.
Ожидаемый результат: два файла с одинаковым содержимым.
Фактический результат: создан hello_backup.txt, оригинал переименован в renamed_file.txt.

6. Сравнение файлов
Команды: cmp, echo $?
Назначение: проверка совпадения файлов.
Ожидаемый результат: код 0 для одинаковых файлов и 1 для разных.
Фактический результат: первоначально получен 0, после добавления строки error: example получен 1.

7. Поиск информации
Команды: grep -n, grep -ni, wc -l, find
Назначение: поиск строк и файлов, подсчёт строк.
Ожидаемый результат: обнаружение искомого текста и файлов.
Фактический результат: error найден в строке 4, Linux в строке 2, подсчитано 4 строки, обнаружено 2 текстовых файла.

8. Просмотр файлов и скрытых элементов
Команды: less, touch .note, ls, ls -a, ls -lh, ls -lt
Назначение: просмотр содержимого, скрытых файлов и свойств каталогов.
Ожидаемый результат: отображение списка файлов в разных форматах.
Фактический результат: скрытый файл .note создан, дополнительные параметры ls проверены.

9. Удаление файла
Команды: rm, ls -l, test -f, echo $?
Назначение: удаление оригинала и проверка резервной копии.
Ожидаемый результат: оригинал удалён, копия сохранена.
Фактический результат: data пустая, hello_backup.txt существует, код проверки 0.

10. Работа с пакетами
Команды: sudo apt update, apt search '^tree$', apt show tree
Назначение: обновление списков пакетов и получение информации о tree.
Ожидаемый результат: обнаружение доступного пакета.
Фактический результат: найден пакет версии 2.1.1-2ubuntu3.24.04.2.

11. Установка пакета
Команды: sudo apt install tree, tree --version, tree ., dpkg-query -W tree
Назначение: установка программы и проверка её работы.
Ожидаемый результат: отображение дерева каталогов.
Фактический результат: программа установлена, структура каталогов показана.

12. Удаление пакета
Команды: sudo apt remove tree, hash -r, command -v tree, echo $?
Назначение: удаление программы и проверка её отсутствия.
Ожидаемый результат: команда tree больше не обнаруживается.
Фактический результат: после очистки кеша команда не найдена, код 1.

Ожидаемый результат: информация без изменения системы.
